# Android 开发预览安装与验收

此安装包用于验证手机端安装、权限和观察能力。当前没有 Hermes 任务连接，
不支持聊天下发任务；默认授权策略拒绝执行远程操作。

## 下载安装

1. 打开仓库 Actions 中通过验证的 `Mobile protocol and Android security kernel` 运行。
2. 下载 `hmr-103-android-evidence`，解压后找到 `app-debug.apk`。
3. 使用 Android 11 或更新版本的测试手机打开 APK，按系统提示允许本次安装。
4. 安装后打开 Hermes 手机运行时。中文系统显示中文说明。

调试包由 CI 临时密钥签名。不同构建可能无法覆盖安装；若系统提示签名冲突，
先卸载旧预览包再安装。卸载会删除本地数据和设备身份。
此包尚未提供用于持续升级的固定内测签名。

## 手机端检查

- 首次打开应显示「开发预览版 · 未连接」，不能显示已经连接 Hermes。
- 点击「设置屏幕观察权限」，在系统设置中启用 Hermes 屏幕观察，再返回应用。
- 返回后可用能力应刷新；未授权时不能宣称屏幕观察已就绪。
- 通知读取是可选项。只在测试需要时启用，并检查返回后状态刷新。
- 从系统设置撤销权限，返回应用检查相应能力消失，应用不崩溃。
- 在测试结束后撤销权限或卸载。

请记录手机型号、Android 版本、构建运行链接、失败步骤和系统错误提示。
报告中不要包含私人通知、聊天内容、密钥或账号凭证。

## 进入实际任务试用前的剩余条件

- 完成受保护的授权服务、设备配对和 HTTPS 传输接入。
- 将 Hermes 请求接入现有 Router、权限检查和审计，不能用测试授权器替代。
- 验证完整任务的前后状态、错误恢复和撤销行为。
- 完成真机验证及内测签名配置。

模拟器通过仅证明自动测试覆盖的场景，不能替代真机验收。
