# Android 内测包安装与验收

仓库现在生成两种 Android 产物：仅验证权限边界的桥接层 APK，以及包含真实
Hermes Agent、可配置模型 API 的 ARM64 内测 APK。iQOO Z10x 应使用后者。
内测包仍是调试签名的 Alpha，不是应用商店正式版本。

## 下载安装

1. 打开仓库 Actions 中通过验证的 `Android native wheel feasibility` 运行。
2. 下载 `hermes-mobile-internal-arm64`，解压后找到
   `Hermes-Mobile-alpha-arm64-v8a.apk`。
3. 使用 Android 11 或更新版本的测试手机打开 APK，按系统提示允许本次安装。
4. 安装后打开 Hermes 手机运行时，配置模型 Base URL、模型名和 API Key。
5. OpenAI 可使用 `https://api.openai.com/v1`；DeepSeek 可使用
   `https://api.deepseek.com`；中转站必须提供 HTTPS 的 OpenAI 兼容接口。

调试包由 CI 临时密钥签名。不同构建可能无法覆盖安装；若系统提示签名冲突，
先卸载旧预览包再安装。卸载会删除本地配置和设备身份。
此包尚未提供用于持续升级的固定内测签名。

## 首次权限和任务检查

- 首次打开应显示「手机内 Hermes Agent 已就绪」。若显示仅含桥接层，说明下载
  了错误的 APK。
- 点击「设置屏幕观察权限」，在系统设置中启用 Hermes 屏幕观察，再返回应用。
- 返回后可用能力应刷新；未授权时不能宣称屏幕观察已就绪。
- 需要通知汇总时启用通知读取；通知只保存在内存中的有界账本和五分钟加密
  工件中。
- 输入一个只读模型任务并发送，确认前台任务通知出现；点击通知中的停止操作
  应立即取消任务和撤销工具桥。
- 从系统选择器选一张图片或一个文件，再明确要求分享到微信。附件只能用于
  下一次已接受的任务，模型不能获得文件路径或 URI。
- 从系统设置撤销权限，返回应用检查相应能力消失，应用不崩溃。
- 在测试结束后撤销权限或卸载。

报告中不要包含私人通知、聊天内容、密钥或账号凭证。

## 当前 Alpha 限制

- 仅提供 ARM64 架构，适配目标是 iQOO Z10x。
- 每次 CI 使用临时调试签名；新包可能需要先卸载旧包，正式持续升级签名尚未配置。
- 支付、转账和安全设置修改继续拒绝或要求用户直接确认。
- 登录密码、短信验证码、扫码和人脸验证必须由用户本人完成。
- `cryptography`、Pillow 和 psutil 相关的 Hermes 可选路径尚未进入内测包。
- 微信联系人选择、发送完成确认以及 OriginOS 锁屏保活仍需要目标手机实测。

模拟器通过仅证明自动测试覆盖的场景，不能替代真机验收。
